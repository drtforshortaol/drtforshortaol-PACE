# RCL first-review prototype

Serve this directory over localhost/HTTPS and open `index.html`. Features: mobile shell, Back fallback, Return to Hub, expandable cards, search, zero external runtime dependencies. Sample data only.

This is an **unpublished source prototype**, not an installed PWA. Offline installation, real MBA content, and integration tests remain future work. The Hub URL is configurable and should be verified against the chosen environment.
